# Weather Diary

**Автор:** [Александр Соколов]

### Описание
GUI-приложение на Python для учета погоды. Позволяет добавлять записи, фильтровать их по температуре и дате, а также сохранять данные в JSON.

### Как запустить
1. Установите Python.
2. Скачайте проект.
3. Выполните: `python weather_diary.py`

### Примеры использования

- **Добавление:** Дата `2023-05-20`, Темп `15`, Описание `Солнечно`.
- **Фильтр:** Введите `10` в "Мин. темп", чтобы увидеть записи выше +10°C.
- **Валидация:** Программа выдаст ошибку при вводе текста вместо температуры или неверного формата даты.
